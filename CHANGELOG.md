# Changelog

## 2.0.0-alpha.1 – 21 Oct 2026
- First standalone native Go preview, no Python requirement on target.
- PHP package, process, binary path, static configuration observations; bounded document-root filenames.
- Offline static repository auditing, Apache/nginx access-log statistical coverage and read-only optional local Docker metadata.
- HTML/JSON/CSV local reports; no overwriting; spreadsheet-safe CSV; HTML escaping.
- Explicit unknown patch and compromise status, log date range, coverage and warnings.
- Hash-keyed, analyst-controlled offline MSSP report rollup.
- No remote CVE probes, no PHP binary execution, no unverified PoC logic, no network calls (except optional local Unix Docker socket).
- Limited test coverage; not approved for public production use.
