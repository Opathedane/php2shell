# PHP2Shell v2.2.0-alpha.1 — official PHP security advisory patch review (unsigned alpha)

- Standalone builds for Linux, Windows and macOS; no target runtime required.
- Uses PHP's official 21 October 2026 fixed-release thresholds (8.5.12 / 8.4.27 / 8.3.36 / 8.2.35).
- The HTML report provides a per-evidence patch assessment and prioritized, explicit follow-up actions. JSON and CSV exports include these assessments.
- **This is not a production-cleared or complete compromise scanner**: backported vendor patches and the serving runtime must be independently verified; no validated PHP2Shell-specific compromise IOCs are bundled.

[Official patch instructions](https://www.php.net/) · [PHP CVE advisories](https://github.com/php/php-src/security/advisories)

Existing releases remain unchanged. Test under controlled authorization before customer deployment.
