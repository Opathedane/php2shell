## What is new

### Unix PHP executable symlink discovery

- Resolve `phpBin`-named file symlink chains within an explicit hop budget (Homebrew Cellar aliases, `/etc/alternatives` chains, versioned `php8.x` / `php-cgi` / `php-fpm` PATH names)
- Inspect the resolved regular file only — never execute PHP or package managers
- Deduplicate installs by resolved path while retaining operator-facing aliases (`via symlink` / `also_via_symlink`)
- Windows file-symlink rejection (`isSafeRegularFile`) and directory reparse behaviour unchanged

### Relevant unresolved candidates

- Permission-denied and over-budget symlink chains leave `PHP_EXECUTABLE_CANDIDATE_UNRESOLVED_NOT_INSPECTED` evidence
- Prevents a soft `NO_PHP_DETECTED_WITHIN_SCAN_COVERAGE` conclusion when a relevant PHP executable candidate could not be inspected
- Broken, circular, and non-regular targets stay silent (no incomplete-scan noise)

## Explicitly out of scope for v2.7.5

- nginx / PHP-FPM pool configuration discovery
- RPM/yum/dnf (or other non-dpkg/apk) package inventory
- Docker / container image inventory
- Homebrew well-known path expansion beyond PATH + existing Linux globs
- Phase A no-PHP messaging redesign beyond the unresolved-candidate honesty fix above
- Changes to CVE-2026-109618 / CVE-2026-109619 upstream thresholds (still 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35)
- Exit-code / status-JSON / fleet CSV schema changes
- Authenticode signing (still unsigned + `SHA256SUMS`)

## Preserved from v2.7.4

- Console UX / reliability polish; OS-aware no-PHP reporting; enterprise quiet/status JSON / PSADT–Intune–GPO contracts; legacy Windows artifact; Apache-2.0

## Limitations (read before deploying)

- Process completion / exit **0** is **not** a vulnerability or compromise clearance
- Missing evidence is **not** a negative finding; active HTTP-serving SAPI is still **not** attested
- PHP installations outside PATH, existing well-known globs, and operator `--config-root` / `--deep-root` remain undiscovered (bounded coverage — not complete host inventory)
- Deep Discovery still does not follow file symlinks as tree edges
- Vendor backports require separate verification
- Binaries remain **unsigned**; verify `SHA256SUMS`
- Interactive Windows console colour behaviour on PowerShell 5.1 / Windows Terminal remains **NOT TESTED**
