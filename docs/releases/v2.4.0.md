# PHP2Shell v2.4.0

Published: **21 October 2026**  
Tag: [`v2.4.0`](https://github.com/Opathedane/php2shell/releases/tag/v2.4.0)

Consultant-oriented release: every scan writes a matching **HTML + CSV** pair; fleet CSVs consolidate offline. Does **not** overwrite `v2.3.0` or `v2.3.1` assets.

## What shipped

- Automatic HTML + CSV pair (`php2shell-fleet-csv/v1`); refuse overwrite; incomplete pair cleanup  
- Offline `rollup --input-dir` / CSV inputs with customer-label conflict checks  
- IIS site/app/vdir + FastCGI discovery (incl. non-`C:` paths); Apache bounded VirtualHost/handler inventory; Tomcat out of scope  
- Preserved v2.3.1 Windows path inference and TestVM 8.4.24 regression  

## Limitations

No active HTTP SAPI attestation; IIS/Apache inheritance/merge not fully simulated; no vendor-backport verification; no compromise clearance from empty IOCs; binaries unsigned.
