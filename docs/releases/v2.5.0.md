# PHP2Shell v2.5.0

Published: **21 October 2026**  
Tag: [`v2.5.0`](https://github.com/Opathedane/php2shell/releases/tag/v2.5.0)

Standalone Windows and Linux scanner for PHP discovery, upstream patch review, and limited compromise-indicator triage. Each scan writes a matching **HTML + CSV** pair; fleet CSVs can be rolled up offline.

## Downloads

- `php2shell-windows-amd64.zip`
- `php2shell-linux-amd64.tar.gz`
- `php2shell-linux-arm64.tar.gz`
- `php2shell-darwin-amd64.tar.gz` / `php2shell-darwin-arm64.tar.gz` (developer convenience builds)

Verify `SHA256SUMS`. Binaries are **not code-signed**. Confirm `php2shell version` prints `2.5.0`.

## What is new

### PHP configuration discovery

- Bounded Windows and Linux `php.ini` / conf.d inventory (well-known roots, sidecars next to discovered binaries, `PHPRC` / `PHP_INI_SCAN_DIR`, IIS `-c` and Apache `PHPIniDir` paths)
- Primary vs sample/template classification (`php.ini-development`, etc.)
- Whitelisted settings observed only — **not** attested as effective for any SAPI
- `php.ini` alone never confirms installation, exact version, active HTTP runtime, or vulnerability status

### Fleet CSV v2

- Schema `php2shell-fleet-csv/v2` with structured `config_*` columns
- Rollup accepts v1 and v2 inputs and writes v2
- HTML + CSV pair generation and multi-server rollup preserved from v2.4.0

### Preserved from v2.4.0

Windows version inference, IIS/Apache bounded web-server discovery, security limitations (no active-SAPI attestation, no compromise clearance from empty IOCs).

## Not in this release (later roadmap)

- Optional `--deep-root` filesystem discovery  
- Native RPM package database inventory  
- Advanced FPM pool ↔ VirtualHost serving-runtime attestation  

See [ROADMAP.md](../ROADMAP.md). Follow-up discovery fixes shipped in [v2.5.1](v2.5.1.md).

## Important limitations

- Does **not** attest which PHP runtime actively serves HTTP  
- Configuration and web-server inventory may be **INCOMPLETE**; that is not a “safe/patched” verdict  
- Does **not** verify vendor security backports  
- Does **not** prove absence of compromise when no indicators match  
- Does **not** execute discovered PHP binaries or upload customer data  
- `customer_label` is not authenticated tenancy
