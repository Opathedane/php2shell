## Supported / unsupported (unchanged product surface)

Supported well-known nginx/FPM layouts, local/remote/ambiguous/variable FastCGI classification, skip/incomplete honesty, no verified runtime from config alone — as documented in `docs/design/nginx-fpm-discovery.md`.

Unsupported: custom prefixes without well-known paths, Homebrew expansion, LiteSpeed/OpenResty-only, Windows nginx, guessing variable backends.

**Honesty reminder for release notes:** nginx/FPM **configuration correlation is never proof** of the active HTTP-serving PHP runtime or its patch state (`EffectiveWebRuntime` remains `NOT_VERIFIED` from config alone).
