| Configuration | Support |
| --- | --- |

| One-hop `sites-enabled` symlink within allowlisted root | Yes |
| Debian/Ubuntu versioned `/etc/php/*/fpm/pool.d` | Yes |

## 6. Remaining false-negative risks

1. **Custom nginx/FPM paths** outside well-known roots  
2. **Homebrew / prefix layouts** (deferred milestone)  
3. **Include depth > 3** or exotic include maps  
4. **Variable-only FastCGI** endpoints (intentionally unresolved)  
5. **Live-only gaps** not yet exercised: packaging side-effects, default pool files from distro packages alongside lab overlays, SELinux/AppArmor denial modes beyond chmod 000  
6. **Remote hostname** forms that are not IP literals (DNS names classify remote when non-loopback — still no connect)
