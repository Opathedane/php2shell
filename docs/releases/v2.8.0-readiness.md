## Scan context (critical)

PHP2SHELL is executed **inside** each scenario’s `scan` container with ordinary well-known path mounts. It is **not** run against the GitHub Actions host filesystem as a proxy for container PHP. See `testdata/nginx-fpm-labs/SCAN-CONTEXT.md`.

Harness diagnostics may start/stop php-fpm to record independent ground truth. **php2shell remains read-only** (no binary execution of discovered PHP, no FastCGI dial).

## Supported / unsupported (unchanged product surface)

Supported well-known nginx/FPM layouts, local/remote/ambiguous/variable FastCGI classification, skip/incomplete honesty, no verified runtime from config alone — as documented in `docs/design/nginx-fpm-discovery.md`.

Unsupported: custom prefixes without well-known paths, Homebrew expansion, LiteSpeed/OpenResty-only, Windows nginx, guessing variable backends.
