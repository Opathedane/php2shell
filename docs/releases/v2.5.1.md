# PHP2Shell v2.5.1

Published: **21 October 2026**  
Tag: [`v2.5.1`](https://github.com/Opathedane/php2shell/releases/tag/v2.5.1)

Bugfix for Windows PATH / junction PHP discovery and clearer multi-installation + php.ini custom-path coverage. Builds on v2.5.0 configuration discovery. Does **not** overwrite `v2.5.0` (or earlier) release assets.

## Downloads

- `php2shell-windows-amd64.zip`
- `php2shell-linux-amd64.tar.gz`
- `php2shell-linux-arm64.tar.gz`
- `php2shell-darwin-amd64.tar.gz` / `php2shell-darwin-arm64.tar.gz` (developer convenience builds)

Verify `SHA256SUMS`. Binaries are **not code-signed**. Confirm `php2shell version` prints `2.5.1`.

## What is fixed

### Windows PATH and `current` junctions

- PATH directory entries that are junctions/reparse points (e.g. `C:\Temp\PHP\current`) are resolved with a **bounded** hop limit and cycle detection, matching what `Get-Command php` / `where.exe` can see
- `%LOCALAPPDATA%\Programs\PHP` trees resolve the same class of `current` aliases during bounded walks
- File symlinks are still rejected; discovered PHP binaries are **never executed**

### Multi-installation discovery

- All eligible PATH entries are inspected (not only the first match)
- Well-known roots, IIS/Apache handler references, and operator `--config-root` combine into separate install records
- Independent installs (including same version in different trees) stay separate; `current` aliases merge only when content-corroborated
- Each install is assessed against its own upstream fix threshold; HTML, CSV, and fleet rollup list every discovered install
- Coverage text states discovery is **bounded, not complete host coverage**

### php.ini custom paths and visibility

- `--php-ini PATH` (repeatable) and `--config-root DIR` (bounded binary + php.ini / `conf.d`, no drive walk)
- php.ini beside PATH-resolved directories; configuration-only evidence clearly labelled (not install/version/runtime proof)
- Unreadable / oversized / symlink file candidates emit `php_ini_skip` (path + reason only; no secrets) in HTML + CSV

### Regressions

- TestVM-style `Temp\PHP\current` (ordinary directory and junction/symlink)
- Three Windows installs on one host: PATH-selected, IIS handler, and `--config-root`
- Hermetic CI isolation so host `/etc/php` trees do not break operator-path fixtures

## Not changed

- No active HTTP SAPI attestation  
- No vendor-backport verification  
- No compromise clearance from empty IOC results  
- No full-disk / `--deep-root` discovery  
- Licensing still pending (`LICENSE.proposed` is not an approved license)

## Quick start

```powershell
.\php2shell-windows-amd64.exe scan --quiet --output-dir C:\ProgramData\PHP2Shell\Reports
# Custom layout example:
.\php2shell-windows-amd64.exe scan --php-ini C:\Temp\PHP\current\php.ini --config-root D:\Apps\PHP
```

```bash
./php2shell-linux-amd64 scan --quiet --output-dir "$HOME/.php2shell/reports"
./php2shell-linux-amd64 scan --php-ini /opt/app/php/etc/php.ini --config-root /opt/app/php
```
