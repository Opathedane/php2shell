# PHP2Shell v2.7.3

> **UNRELEASED DRAFT** — Do not tag or publish until PR #28 is approved and merged. Latest public release remains **v2.7.2**.

Patch release focused on **no-PHP detection reporting** and HTML usability after field testing of v2.7.2 on Windows hosts without PHP.

## Highlights

- Classify no-PHP outcomes only when applicable discovery sources completed successfully.
- Keep genuine Windows discovery failures visible (IIS, PATH/filesystem, process inventory, access denied / unavailable).
- Do not surface Linux package-manager gaps on Windows.
- Never imply the host is PHP-free, patched, or uncompromised.
- Preserve exit codes, fleet CSV schema, and status JSON execution semantics.

## Does not change

- Vulnerability thresholds for CVE-2026-109618 / CVE-2026-109619
- Scanner discovery capabilities (no new scan features)
- The published **v2.7.2** tag or release artifacts
