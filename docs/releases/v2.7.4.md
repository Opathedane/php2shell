# PHP2Shell v2.7.4

**Unreleased draft — do not tag or publish until approved.**

Patch release: console UX and reliability polish for ordinary IT administrators and enterprise deployments. Preserves v2.7.3 detection, exit codes, status JSON, CSV, and fleet consolidation. No new scanning features, CVEs, or WAF/DFIR integrations.

**Latest public release remains [v2.7.3](v2.7.3.md).** Confirm `php2shell version` on the binary you run.

## Intended downloads (after publish)

- `php2shell-windows-amd64.zip` — Windows 10 / Server 2016+ (primary Go toolchain)
- `php2shell-windows-legacy-amd64.zip` — **Go 1.20.14** build for Windows Server 2012 R2 testing
- `php2shell-linux-amd64.tar.gz` / `php2shell-linux-arm64.tar.gz`
- `php2shell-darwin-amd64.tar.gz` / `php2shell-darwin-arm64.tar.gz`

## What is new

### Windows console compatibility

- Explicit `--no-color` (also respects `NO_COLOR`)
- Best-effort Windows Virtual Terminal enablement with safe plain-text fallback (Server 2012 R2 / legacy conhost)
- Stdout and stderr terminal capabilities handled independently

### Clearer end-of-scan assessment (CLI)

- Overall priority and recommended next step aligned with HTML
- Installation review uses `GroupInstallations` (no hidden independent installs)
- Windows hosts no longer show Linux dpkg/apk package-DB warnings
- Investigation statuses humanized; process completion still ≠ clearance

### HTML / errors / tests

- `:focus-visible` outlines on collapsible sections
- Clearer multi-install mixed patch-level executive detail
- `ACCESS_DENIED` remediation for failed report writes
- Console/HTML phrase regressions and built-binary smoke (`version` / `doctor`)

## Explicitly out of scope

- New CTI/IOC packs, discovery features, CVE threshold changes
- Exit-code / status-JSON / fleet CSV schema changes
- Authenticode signing
