PHP2Shell macOS CI fix – 21 October 2026

Root cause:
- CI selected Go 1.21 from go.mod on macOS latest (macOS 26).
- Older Go test executables lack the required Mach-O LC_UUID load command.
- Release build flags also removed the Go build ID; retain build IDs.

Changes:
- The three GitHub Actions workflows pin Go 1.27.3 and disable unused go.sum caching.
- Build scripts retain the standard Go build ID.
- go.mod remains at 1.21 (minimum declared source language version).

GitHub Desktop steps:
1. In Finder open ~/Developer/php2shell.
2. Extract this ZIP elsewhere, and copy the .github and scripts folders into the repository, selecting Merge/Replace. Do not remove the repository's .git directory.
3. In GitHub Desktop inspect the four changed files.
4. Commit summary: fix(ci): use modern Go toolchain for macOS tests and builds
5. Push origin.
6. Open GitHub Actions and check all three platform test jobs complete.
7. Publish no release until tests pass.
